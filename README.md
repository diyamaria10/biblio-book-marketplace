# Biblio – Student Second-Hand Book Marketplace

Biblio is a web-based platform designed to make buying and selling second-hand books easier for students. It provides a place where students can list books they no longer need and find affordable books from other sellers.

## Features

- User registration and login
- Separate user and admin dashboards
- Browse and search book listings
- View individual book details
- Sell books by creating listings
- Add books to cart and checkout
- Place and manage orders
- Track order and delivery status
- Courier assignment and delivery management
- Seller ratings
- Notifications and order updates

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP (local development environment)

## Getting Started

### Prerequisites

- XAMPP
- A web browser
- Git

### Installation

1. Clone this repository into the XAMPP `htdocs` directory.
2. Create a MySQL database named `BIBLIO`.
3. Import the database SQL file (when provided).
4. Copy `db.example.php` and rename the copy to `db.php`.
5. Update the database credentials in `db.php`.
6. Start Apache and MySQL from XAMPP.
7. Open the following URL in your browser:

   http://localhost/project/index1.php

## Database Configuration

The actual `db.php` file is excluded from this repository to protect local database credentials.

Use `db.example.php` as a template and enter your own MySQL configuration.
